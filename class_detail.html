How to Write Exam Rules

Playbook's AI grading engine reads every single answer a student writes. If a student answers 3 questions when they were only supposed to answer 2, Playbook will grade all 3, but it will automatically drop their lowest score so they don't get an unfair advantage.

To enable this, you MUST type your rules exactly like these examples (put each rule on a new line):

Example 1 (Specific Section):

Section B: answer 2 Answer 2 questions in Section C

Example 2 (Entire Exam):

Attempt 3 questions
